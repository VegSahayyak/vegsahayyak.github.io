🚀 v2.2.1 (Latest Stable) ​

🛡️ Reliability & Security Fixes ​

  • Native Library Loader Resilience (libspatial.so):
    • Added graceful UnsatisfiedLinkError exception handling on Android Dalvik/ART runtimes when the native .so cannot be mapped or extracted.
    • Instead of an unhandled VM crash, the SDK fails closed securely with VegSahayyakLicenseException (code 5), protecting commercial licensing while allowing host applications to log the event non-fatally to Crashlytics.
  • Android 14+ FGS Location Permissions:
    • Validates fine or coarse runtime location permissions before passing FOREGROUND_SERVICE_TYPE_LOCATION to ServiceCompat.startForeground(), safely guarding against runtime SecurityException.
  • Android 12+ Background Start Protection:
    • Added safe guards around SpeedometerService.setRunningState() and SpeedAssistant.start() to safely intercept ForegroundServiceStartNotAllowedException when background execution restrictions are active.

🎨 UI & Modular Refinements ​

  • Floating PiP Overlay Lifecycle Suppression:
    • Bound OverlayService to ProcessLifecycleOwner to automatically hide (View.GONE) the floating speedometer whenever host activities enter the foreground, restoring it seamlessly when backgrounded.
  • SpeedGauge Center Clearance:
    • Adjusted gauge center offset across portrait and landscape modes to ensure comfortable clearance between speed unit labels (km/h ▼) and the needle pivot hub.
  • SDK Resource Decoupling:
    • Cleanly decoupled legacy application layouts, menus, launcher drawables, and strings from :speed-core and :speed-ui. The SDK is now completely pure and prevents namespace pollution in host applications.

📦 v2.2.0 ​

🌟 New Features & Enhancements ​

  • Native C++ Telematics Vault:
    • Core GPS verification, EMA algorithms, and JWT license parsing are now executed inside an obfuscated C++ .so vault (libveg_vault.so) to prevent Dalvik/ART hooking.
  • Flexible Commercial Licensing:
    • Completely replaced Firebase authentication with offline-first JWT (JSON Web Token) commercial license keys that encode module access and expiry dates directly in the payload.
  • Sample Applications Monorepo:
    • Released the veg-sahayyak-samples repository featuring 6 B2B integrations (Basic, Fleet, UBI, Background, Custom UI, OEM).

🟡 v2.1.0 (Legacy Stable) ​

🌟 New Features & Enhancements ​

  • Voice Commands & Driving Profiles:
    • Introduced VoiceCommandButton and VoiceCommandParser for hands-free mode switching.
    • Replaced manual limit configuration with legal DrivingProfile bounds (e.g. CarHighway, SchoolZone).
  • Client Theme & Color Scheme Injection:
    • Added SpeedColorScheme (:speed-core) and SpeedUiColorScheme (:speed-ui) allowing host apps to inject custom brand colors.
    • Propagates brand colors across SpeedGauge, HudDisplay, PipWidget, and foreground NotificationProvider.
  • HUD Windshield Reflection Mode:
    • Added Modifier.hudMirror() for vertical/horizontal axis transformations.
    • Added HudDisplay standalone composable with true OLED black (#000000) background and high-visibility 120sp typography.
    • Integrated HUD mirroring into SpeedGauge and ThemeMode.HUD_MIRRORED.
  • Decoupled Architecture Modules:
    • :speed-overlay: Standalone floating Picture-in-Picture speedometer widget (PipWidget).
    • :speed-autostart: Zero-touch background trip detection via Google Play Activity Recognition (AutoStartManager).

🐛 Bug Fixes ​

  • False Minimum Speed Alarms: Implemented 8 km/h Stationary Suppression in TelematicsEngine. The under-speed alarm is now aggressively silenced when the vehicle is in heavy traffic or navigating speed bumps.

  • API 25 Crash Fix: Resolved VectorDrawable inflation crashes on Android Nougat (API 25).

  • AAPT2 String Errors: Fixed missing localized string resources triggering AAPT2 compilation failures during :app assembly.

  • CI/CD Quality Gates & Coverage:

    • Aggregated multi-module JaCoCo coverage reporting (jacoco.gradle.kts).
    • Verified full ProGuard consumer rules and zero-warning Lint passes.

🔄 Migration Guide: v1.x → v2.0.x ​

Version 2.0 represents a major architectural overhaul, splitting the codebase into modular SDK components:

1. Update Gradle Dependencies ​

Replace legacy monolithic imports with the modular BOM:

kotlin
// Old (v1.x)
implementation("com.vegsahayyak:speed-assistant:1.2.0")

// New (v2.x Modular)
implementation(platform("com.vegsahayyak:speed-bom:2.0.2"))
implementation("com.vegsahayyak:speed-core")
implementation("com.vegsahayyak:speed-ui")

2. Update Initialization Pattern ​

Replace static singleton access with the manual service locator builder:

kotlin
// Old (v1.x)
SpeedAssistantManager.getInstance().start(context)

// New (v2.x)
SpeedAssistant.with(context, "YOUR_JWT_LICENSE")
    .setDrivingProfile(DrivingProfile.CarHighway)
    .start()
