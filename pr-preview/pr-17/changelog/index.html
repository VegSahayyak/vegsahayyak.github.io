🚀 v2.1.0 (Latest Stable) ​

🌟 New Features & Enhancements ​

  • Voice Commands & Driving Profiles:
    • Introduced VoiceCommandButton and VoiceCommandParser for hands-free mode switching.
    • Replaced manual limit configuration with legal DrivingProfile bounds (e.g. CarHighway, SchoolZone).
  • Client Theme & Color Scheme Injection:
    • Added SpeedColorScheme (:speed-core) and SpeedUiColorScheme (:speed-ui) allowing host apps to inject custom brand colors.
    • Propagates brand colors across SpeedGauge, HudDisplay, PipWidget, and foreground NotificationProvider.
  • HUD Windshield Reflection Mode:
    • Added Modifier.hudMirror() for vertical/horizontal axis transformations.
    • Added HudDisplay standalone composable with true OLED black (#000000) background and high-visibility 120sp typography.
    • Integrated HUD mirroring into SpeedGauge and ThemeMode.HUD_MIRRORED.
  • Decoupled Architecture Modules:
    • :speed-overlay: Standalone floating Picture-in-Picture speedometer widget (PipWidget).
    • :speed-autostart: Zero-touch background trip detection via Google Play Activity Recognition (AutoStartManager).

🐛 Bug Fixes ​

  • False Minimum Speed Alarms: Implemented 8 km/h Stationary Suppression in TelematicsEngine. The under-speed alarm is now aggressively silenced when the vehicle is in heavy traffic or navigating speed bumps.

  • API 25 Crash Fix: Resolved VectorDrawable inflation crashes on Android Nougat (API 25).

  • AAPT2 String Errors: Fixed missing localized string resources triggering AAPT2 compilation failures during :app assembly.

  • CI/CD Quality Gates & Coverage:

    • Aggregated multi-module JaCoCo coverage reporting (jacoco.gradle.kts).
    • Verified full ProGuard consumer rules and zero-warning Lint passes.

🚀 v2.0.2 ​

🌟 New Features & Enhancements ​

  • TelematicsEngine Signal Pipeline:
    • Implemented Exponential Moving Average (EMA) with α = 0.3 smoothing to eliminate jitter from raw GPS sensor readings.
    • Added confidence gating to automatically discard GPS fixes exceeding 25.0m inaccuracy.
    • Introduced Dual Schmitt Trigger Hysteresis (+1.0 km/h alert, -3.0 km/h dismissal) to prevent alarm fluttering.
  • Jetpack Compose UI Gallery (:speed-ui):
    • Added hardware-accelerated SpeedGauge canvas component with smooth 60fps needle animations.
    • Added high-contrast and OLED dark theme presets.
    • Integrated real-time GPS accuracy pill badge (Good, Fair, Weak).
  • Bill of Materials (:speed-bom):
    • Added Gradle platform BOM artifact for aligned SDK dependency resolution.

🔄 Migration Guide: v1.x → v2.0.x ​

Version 2.0 represents a major architectural overhaul, splitting the codebase into modular SDK components:

1. Update Gradle Dependencies ​

Replace legacy monolithic imports with the modular BOM:

kotlin
// Old (v1.x)
implementation("com.vegsahayyak:speed-assistant:1.2.0")

// New (v2.x Modular)
implementation(platform("com.vegsahayyak:speed-bom:2.0.2"))
implementation("com.vegsahayyak:speed-core")
implementation("com.vegsahayyak:speed-ui")

2. Update Initialization Pattern ​

Replace static singleton access with the manual service locator builder:

kotlin
// Old (v1.x)
SpeedAssistantManager.getInstance().start(context)

// New (v2.x)
SpeedAssistant.with(context)
    .setDrivingProfile(DrivingProfile.CarHighway)
    .start()
