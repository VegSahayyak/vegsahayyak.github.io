🚗 Driving Profiles & Speed Corridors ​

The Veg Sahayyak SDK includes a legally compliant, globally localized Driving Profiles system (DrivingProfile.kt) designed to configure speed warning corridors in a single function call.

🎯 Why Driving Profiles? ​

Traditional speed limit apps perform naive floating-point conversions (e.g. converting $120\text{ km/h}$ gives $74.5645\text{ mph}$), leading to awkward numbers on driver dashboards.

DrivingProfile provides explicitly rounded, legally localized speed limits for each vehicle type and speed unit ($120\text{ km/h}$ for Europe vs $75\text{ mph}$ for US interstate highways).

📦 Applying a Driving Profile ​

Apply any predefined profile to SpeedAssistant:

kotlin
import com.vegsahayyak.speedcore.api.SpeedAssistant
import com.vegsahayyak.speedcore.api.DrivingProfile

// Apply standard Highway Profile with 1 line of code
SpeedAssistant.with(context)
    .setDrivingProfile(DrivingProfile.CarHighway)
    .start()

🛠️ Dynamic Cloud Limits (CustomProfile) ​

If your fleet application integrates with the Google Roads API, HERE Maps, or OpenStreetMap to ingest real-time geofenced legal speed limits, use DrivingProfile.CustomProfile:

kotlin
import com.vegsahayyak.speedcore.api.DrivingProfile
import com.vegsahayyak.speedcore.units.SpeedUnit

// Dynamically received 65 mph limit from cloud GPS corridor
val dynamicLimitFromMap = 65f
val minimumCorridorLimit = 40f

val roadProfile = DrivingProfile.CustomProfile(
    maxLimit = dynamicLimitFromMap,
    minLimit = minimumCorridorLimit,
    unit = SpeedUnit.MILES_PER_HOUR
)

// Ingest into SpeedAssistant
SpeedAssistant.with(context).setDrivingProfile(roadProfile)

The SDK automatically converts custom bounds to SI units ($m/s$) internally while maintaining display accuracy for any user-selected gauge unit.

🧪 Unit Testing Driving Profiles ​

DrivingProfile is designed to be easily testable without requiring Android context or mock hardware:

kotlin
@Test
fun verifyHighwayLimitsMetricAndImperial() {
    val highway = DrivingProfile.CarHighway
    
    // Metric validation
    assertEquals(120f, highway.getMaxLimit(SpeedUnit.KILOMETERS_PER_HOUR))
    assertEquals(60f, highway.getMinLimit(SpeedUnit.KILOMETERS_PER_HOUR))
    
    // Imperial validation
    assertEquals(75f, highway.getMaxLimit(SpeedUnit.MILES_PER_HOUR))
    assertEquals(40f, highway.getMinLimit(SpeedUnit.MILES_PER_HOUR))
}
