🚀 SpeedAssistant ​

Singleton Builder package com.vegsahayyak.speedcore.api

The primary entry point to the telematics engine.

Builder & Lifecycle Methods ​

companion object.with(context: Context): SpeedAssistant ​

Retrieves or instantiates the singleton instance of SpeedAssistant. Automatically initializes core dependencies.

setWarningSpeedThreshold(limitInUserUnit: Float): SpeedAssistant ​

Sets the maximum speed ceiling. Converts user units to SI meters/second and updates TelematicsEngine.

setMinWarningSpeedThreshold(limitInUserUnit: Float): SpeedAssistant ​

Sets the minimum speed corridor limit.

setDrivingProfile(profile: DrivingProfile): SpeedAssistant ​

Applies a pre-configured or dynamic DrivingProfile and automatically resolves the ideal max and min speed limits according to the user's active unit.

setWarningPendingIntent(intent: PendingIntent): SpeedAssistant ​

Configures the PendingIntent fired when the driver breaks the speed threshold.

setColorScheme(colorScheme: SpeedColorScheme): SpeedAssistant ​

Configures custom brand colors for system notifications and alerts across the SDK.

useRepository(repository: ISpeedRepository): SpeedAssistant ​

Overrides the internal default SpeedRepositoryImpl with a custom implementation or test double (e.g. FakeSpeedRepository).

usePreferenceRepository(repository: IPreferenceRepository): SpeedAssistant ​

Overrides the internal persistent preferences repository with a custom implementation.

val tracker: ISpeedRepository ​

Direct accessor to the active speed repository instance.

val preferences: IPreferenceRepository ​

Direct accessor to the active persistent preferences repository instance.

start() ​

Starts the SpeedometerService foreground service and begins Fused Location Provider polling.

startIfEnabled(): Boolean ​

Checks user preferences and restarts the tracking service only if it was previously active. Returns true if started.

stop() ​

Halts the foreground service, removes location updates, and resets the TelematicsEngine.

companion object.observeFlow(): Flow<SpeedData> ​

Returns a Kotlin Coroutines Flow of real-time telematics updates.

⚙️ TelematicsEngine ​

Internal Domain package com.vegsahayyak.speedcore.domain

Performs mathematical signal smoothing and state machine transitions.

kotlin
data class TelematicsResult(
    val smoothedSpeedMps: Float,
    val isOverLimit: Boolean,
    val isUnderLimit: Boolean,
    val accuracyMeters: Float
)
  • processLocation(rawSpeedMps: Float, accuracyMeters: Float): TelematicsResult?: Applies accuracy confidence gating (25m), Exponential Moving Average (α = 0.3), and Schmitt Trigger Hysteresis (+1.0 km/h / -3.0 km/h). Returns null if precision is insufficient.
  • reset(): Flushes historical momentum states.

🚗 DrivingProfile ​

Sealed Class package com.vegsahayyak.speedcore.api

Pre-configured speed limit profiles for various vehicle classes and environments.

kotlin
sealed class DrivingProfile {
    abstract val maxKmh: Float
    abstract val minKmh: Float
    abstract val maxMph: Float
    abstract val minMph: Float

    fun getMaxLimit(unit: SpeedUnit): Float
    fun getMinLimit(unit: SpeedUnit): Float

    object CarHighway : DrivingProfile()          // Max 120 km/h / 75 mph, Min 60 km/h / 40 mph
    object CarCity : DrivingProfile()             // Max 50 km/h / 30 mph, Min 0
    object Motorcycle : DrivingProfile()          // Max 120 km/h / 75 mph, Min 0
    object TruckHighway : DrivingProfile()        // Max 90 km/h / 60 mph, Min 50 km/h / 30 mph
    object BusCoach : DrivingProfile()            // Max 100 km/h / 65 mph, Min 50 km/h / 30 mph
    object TractorAgricultural : DrivingProfile() // Max 40 km/h / 25 mph, Min 0
    object EScooter : DrivingProfile()            // Max 20 km/h / 12.5 mph, Min 0
    object Bicycle : DrivingProfile()             // Max 25 km/h / 15 mph, Min 0
    object Walking : DrivingProfile()             // Max 8 km/h / 5 mph, Min 0
    object SchoolZone : DrivingProfile()          // Max 30 km/h / 20 mph, Min 0

    data class CustomProfile(
        val maxLimit: Float,
        val minLimit: Float,
        val unit: SpeedUnit
    ) : DrivingProfile()
}
